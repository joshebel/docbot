**Gig description**

Your code changed; your docs didn't. I fix that from the source itself.

You give me access to the repository (read-only is enough). I map the file tree, extract
every public function, class and endpoint with its signatures and docstrings, read the
parts that matter, and write documentation that describes what the code actually does today.
Delivered as a pull request so you review every line before it merges.

What you get depends on the tier (see table). Every tier includes: real install/usage commands
lifted from your code, no invented APIs, and a clarifying question list for anything the code
doesn't make obvious.

Process: I use a documentation pipeline I built and run on my own hardware — your code does
not go to a third-party AI vendor — then review and edit every page myself. That's why I can
promise days, not weeks, at a fixed price.

Please have ready: repo access, who the docs are for (users, contributors, or both), and any
house style I should match.

**FAQ**
- *Is this AI-generated?* AI-assisted and human-reviewed. The extraction and first draft are
  automated from your source; I review, correct, and edit before delivery.
- *Private repos?* Yes. Read-only collaborator access or a zip. Code is deleted after delivery.
- *Monorepos / multiple languages?* Standard handles two; Premium handles any mix.
- *What if the repo is bigger than the tier?* I'll tell you before starting and quote the difference.
