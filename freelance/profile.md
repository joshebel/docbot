# Upwork profile

**Title** (70 chars max)
Codebase Documentation: README, Module Guides & API Reference from Source

**Hourly rate**: $45/hr (used for scoping calls only; projects are fixed-price)

**Overview**

I write documentation directly from your source code — not from a form you fill out.

Send me repo access and within three business days you get a pull request containing:

- a README with the actual install and usage commands your code supports,
- one guide per module: what it's for, its key components, entry points, and gotchas,
- an API reference of your public functions, classes, and endpoints.

Everything is derived from the code as it is today, so it matches reality instead of the
plan from six months ago. You review the PR like any other; nothing lands without your merge.

How I work: I use a documentation pipeline I built (tree + signatures + selective source
reading, running on my own hardware — your code never goes to a third-party AI service on the
standard tier) and then review and edit every page by hand. That's how I can quote a fixed
price in advance and deliver in days rather than weeks.

Good fit: Python, TypeScript/JavaScript, Go, Rust, Java, C#, PHP, Ruby codebases from 1k to
~200k lines; internal tools, SDKs, CLIs, services, and open-source projects that have
outgrown their README.

Not a fit: marketing copy, end-user manuals for non-technical audiences, or repos you don't
have the rights to share.

Fixed-price packages start at $350 (README + one module). Ask for a quote — I read the repo
before I answer, and the proposal will name your actual modules.
