# Terms of Service — docbot

_Last updated: 2026-09-16_

## The service

docbot is a GitHub App that generates documentation for repositories it is installed on and
proposes it as a pull request. Nothing is merged automatically; every change is subject to
your review.

## Intended use and limitations

- Output is produced by machine-learning models and may contain errors or omissions. Review
  it as you would any contributor's pull request before merging.
- docbot is designed for source repositories. It refuses repositories over a size cap and
  skips vendored, generated and binary content.
- docbot does not perform content moderation of your repository; it documents what is there.
- Availability is best-effort on the Free plan. The Pro plan receives priority in the queue and
  may use a third-party model provider (see the Privacy Policy) but carries no uptime guarantee.

## Your responsibilities

- You must have the right to grant docbot access to the repositories you install it on.
- Do not install docbot on repositories containing content you are not permitted to send to
  the processing described in the Privacy Policy.

## Plans and billing

Paid plans are billed through GitHub Marketplace under GitHub's terms. Cancelling a plan
downgrades the account to Free at the end of the billing period; docbot honours the downgrade
as soon as GitHub notifies it.
